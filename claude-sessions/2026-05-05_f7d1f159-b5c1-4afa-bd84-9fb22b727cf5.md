## How the session file naming works

| Factor | Value | Result |
|---|---|---|
| Each Claude Code session | Gets a unique UUID (e.g. `0ad58b80-...`) | Always a different ID |

| New session next day | New UUID → new file | Separate file, even in same project |

## Multiple sessions in the same repo

| Scenario | What happens |
|---|---|

| All pushed to | Same repo, same branch, different files |

| Setting location | Scope |
